# Shot 表达方式（3 类镜头调色盘）

表达方式决定“这一镜靠什么让观众一眼看懂”，MG 视觉语法决定“它看起来像同一部 Google 商业片”。先按本文件选定表达方式，再按 [mg-design.md](mg-design.md) 设计画面与动效。

## 选型原则：不是死板唯一解，而是全片节奏调色盘

同一句话往往 3 种都能拍，选哪一种看两件事：
1. **这一句此刻最想给观众什么感受**（直接亮观点/摆数据 → 直接信息；讲清原理/抽象转译/炫产品感 → 视觉化展示；拉共情/演冲突 → 剧情推动）；
2. **与上一镜主动错开节奏**：避免连续多镜都偷懒做成纯文字的“直接信息”（相邻纯文字主镜建议不超过 2 镜），让直接信息、视觉化展示和剧情推动在全片交替呼吸。若某一句两种演法都很出彩，在设计思路里主推 1 种并附 1 句备选方向交给用户拍板。

---

## 3 类表达方式

### 1. `direct_info` 直接信息（文字 / 数据 / 图表 / 表格 / 清单）
- **适用**：标题、金句观点、价格、百分比、额度对比、表格与总结清单——信息本身直接呈现就是最强表达。
- **核心画法**：
  - 文字/观点/清单：非对称海报排版、悬殊字号对比、大色面斜切/遮罩、前景磨砂卡片强 2.5D 视差；
  - 数据/表格：巨型主数值 + 与数值严格成比例的磨砂玻璃进度条 / 柱状图 / 容量块 / 对照卡片（不编造假数据、不重复同一数字）。

### 2. `visual` 视觉化展示（文字以外的视觉化演绎）
- **适用**：需要给出文字以外的画面表达——产品原理、操作流程、系统连接、**UI 元素化微剧情**，以及无现实载体的抽象机制与隐喻。
- **核心画法**：围绕 1 个核心主体 + 2–3 个定制商业图形或磨砂玻璃 UI 模块，**演完一次清晰的“起点形态 → 终点形态”连续变化**；去掉文字后，观众凭画面动作本身就能读懂核心含义，文字只做辅助短标签。
- **常见演法**：
  - **产品/结构演绎**：芯片连接云端、概念相机聚焦光学环、画廊展开多比例成图、节点驱动光标；
  - **UI 元素化微剧情**：用磨砂卡片 + 光标动作 + 槽位反馈演痛点（如“只有口播稿，连画面都没想好” → 光标连点空分镜槽弹红问号回弹）；
  - **图形隐喻**：先定唯一映射且首尾不变（如“灵感变方案 → 断路地图连成通路”、“淘汰筛选 → 珊瑚红斜条扫空空白卡片”）。

### 3. `story` 剧情推动（人物行动 / 情绪 / 小事件）
- **适用**：以具体人物的动作、情绪反应或小事件推进叙事（如改稿崩溃、灵光一闪、沟通受阻）。
- **核心画法（已验证标杆路线 · 绝不用真人实拍）**：
  - **人物画风**：统一采用 **Google Brand Studio / Buck 级精良现代 2D 商业矢量插画人物**——利落发型、干净克制的五官神态（不要无五官简陋剪影、不要低多边形、不要 3D 卡通、**不要真人实拍**）、现代简约穿搭与清晰 2D 平面分层色块；
  - **舞台融合**：人物置于同一块通透抽象色场与极简几何道具上，周围悬浮同款**磨砂玻璃 UI 卡片**（卡片内部只用抽象色条与圆点，**零内部假小字**）推进剧情，与前后纯 MG 镜头无缝混剪；
  - **单镜一事**：一个 Shot 只演一个清晰动作与情绪转折。

## 连续性锚点

仅在同一镜连续形变，或同一人物/核心对象跨镜重复出现时，保持人物外观穿搭或对象的形状、比例、单位与隐喻映射前后一致，不中途重绘或偷换概念。
