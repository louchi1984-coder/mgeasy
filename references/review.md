# 独立盲审（Omni 2.0）

每个 Shot 交付给用户之前，另起一个独立子 agent 评审（设计者不自审）。

## 传给评审者的材料

只传以下信息，**不传设计笔记或内部草稿**：
- 当前镜口播 / 字幕原文
- 获准可见文字白名单（`visible_text`）
- 完整英文 Prompt 原文
- 目标档位时长、比例、衔接模式（首尾帧 / 纯文生色场 / 动势硬切 / 单镜）、当前镜位置（首镜 / 中间镜 / 末镜 / 单镜）
- 上一镜出口状态（如有）
- [gold-examples.md](gold-examples.md)

> 开头风格锚点、一镜到底声明、`3–15s` 整数时间段连续覆盖、白名单逐字出现、禁用词（`--ar`/JSON/Hex/`1px`/元指令/`lens`/`icons`/`live-action`/写实词）与篇幅检查已由 `validate_delivery.py prompt` 自动完成，评审者专注以下 6 项视觉与商业质感判断。

## 评审 6 项（只查这 6 项，不吹毛求疵）

1. **表达方式落地**：核对当前镜选定的表达方式（`direct_info` 直接信息 / `visual` 视觉化展示 / `story` 精良 2D 商业插画人物剧情，禁止真人实拍）是否真正落地。若选了 `visual` 或 `story`，去掉文字后观众凭画面变化应能读懂核心含义；若明明需要视觉化展示却偷懒做成“大字居中 + 无关装饰卡片”，判 `FAIL`。
2. **文字空间绑定、纯平质感与可读性**：获准文字是否自然绑定在具体的画面位置与视觉层级上（非生硬罗列），完整字形直接呈现、高对比清晰；除非用户明确要求立体/特殊材质字，默认须为**纯平 2D 锐利无体积感文字**，中文短语简洁不拥挤。
3. **商业级美学与材质克制**：开场/高潮镜是否具备大厂发布会级的商业美学冲击力（不落入小家子气的“直译图解”）；对象是否一眼可辨且无实景/杂乱软件界面；材质是否克制多变（不机械堆砌磨砂玻璃导致视觉疲劳）；若为 `story` 镜，2D 插画人物必须有精致现代造型与克制神态（非简陋剪影），且悬浮 UI 卡片须明确零内部小字。
4. **严格因果顺序与同体连续演变**：核对开场段是否**没有提前剧透**后半段才出现的文字、卡片或纯色转场块；元素出场先后依赖是否清晰无矛盾；形态演变是否为同一对象的物理连续变形（非凭空冒新物体，且变形各阶段结构清晰可辨、不过度极简）。
5. **快起脆落动势与 2.5D 运镜**：是否具备干脆利落的 AE 弹跳/瞬切节奏与明确的 2.5D 摄像机路径，避免慢吞吞飘动或平贴 PPT 感。
6. **入场与结尾衔接**：有上一镜时是否准确承接其入口（首尾帧自然延续、纯文生同色全屏场展开，或动势硬切方向顺接）；有下一镜且用纯色场接力时，结尾是否由主体放大或画外扫入全高纯色遮罩完成（非画边提前停一块蓝板），且**不含 `Google-blue` 等品牌色名**并标明 `zero logos`；末镜是否干脆定格在清楚可读的最终画面。

## 输出与闭环

评审一次完成，逐项给出 `PASS / FAIL`，对 `FAIL` 项用 1–2 句写明原因和改法。个人配色偏好不在评审范围，交由用户看片判断。

设计者只修改 `FAIL` 项，改完重跑 `validate_delivery.py prompt --shot <id>` 通过后再交付用户确认。
