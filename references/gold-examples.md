## 反例（不得交付）

1. 廉价剪贴画风：把主体写成 `page icons`、`centered on a single flat color`，导致画面干瘪像免费 PPT 模板。
2. 跑偏写实风：写入 `lens`、`photorealistic`、`real-world`、`thick paper stack`、实景桌面或复杂真软件菜单截屏。
3. 慢吞吞缺乏动效感：满篇 `slowly floats`、`gradually fades`，缺少快起脆落的 AE 弹跳、瞬切与 2.5D 摄像机冲劲。
4. 堆砌旧式防御模板：塞入 `--ar 16:9`、`Display only these exact strings: [...]` JSON 数组、`#xxxxxx` Hex 色码、40 词免责声明或 `Let the model choose` 等元指令。
